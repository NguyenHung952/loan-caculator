# 💰 Loan Calculator

> Công cụ web tính toán **khoản vay** và các thông số tài chính cơ bản trực tiếp trên trình duyệt.

## ✨ Tính năng

- Nhập các thông số khoản vay.
- Tính toán kết quả bằng JavaScript.
- Hiển thị kết quả ngay trên giao diện.
- Giao diện nhẹ, không cần backend theo cấu trúc hiện tại.

## 🧱 Cấu trúc

```text
loan-caculator/
├── index.html      # Giao diện
├── script.js       # Logic tài chính
├── styles.css      # UI
└── README.md
```

## 🚀 Chạy

Mở `index.html` bằng trình duyệt hiện đại hoặc chạy bằng static web server.

## 🛠️ Công nghệ

`HTML5` · `CSS3` · `JavaScript`

## 🎓 Mục đích

Dự án phục vụ thực hành **form input, JavaScript, phép tính tài chính và hiển thị dữ liệu** trên web.

> Kết quả chỉ mang tính tham khảo; công cụ không thay thế tư vấn tài chính chuyên nghiệp.
