# Loan Calculator

Ứng dụng web tính toán khoản vay, hỗ trợ nhập các thông số tài chính và xem kết quả trực tiếp trên giao diện.

## Cấu trúc

```text
loan-caculator/
├── index.html
├── script.js
├── styles.css
└── README.md
```

## Thành phần

- `index.html`: giao diện nhập dữ liệu.
- `script.js`: logic tính toán khoản vay.
- `styles.css`: giao diện và bố cục.

## Mục đích

Phù hợp để thực hành JavaScript, xử lý biểu mẫu và các phép tính tài chính cơ bản trên web.

> Giữ nguyên mã nguồn hiện có; chỉ cập nhật README để repository rõ ràng hơn.
